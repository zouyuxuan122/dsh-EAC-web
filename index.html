THE FULL PICTURE

深入解读 About

官方开源 agent harness
的桌面化完全体

DeepSeek Harness EAC（揽尽万象） 是 DeepSeek AI 官方开源的 agent harness —— dsh（DeepSeek Harness）的桌面客户端封装。 它将完整的 @deepseek-ai/dsh 及其全部插件打包进一个开箱即用的桌面应用： 免安装 Node.js、双击即用、离线可用，同时保留 dsh 的全部能力 —— 子代理、工具注册表、 沙箱隔离、会话日志、Skills、MCP 与插件市场，一切皆插件，处处可替换。

外壳由 Electron 承载：自绘无边框玻璃栏、系统托盘常驻、会话完成通知、余额小部件、 文件变更追踪与还原、会话内终端、HTML 与端口预览；底层 dsh 引擎通过内置运行时在 本机回环地址运行，不对外暴露任何端口。

01

免安装 Node 运行时

内置独立 node.exe 与 npm CLI，目标机器零环境依赖；预编译原生模块 ABI 与内置运行时严格一致，开箱即用。

02

完整内置 dsh 引擎

打包 @deepseek-ai/dsh 全量插件：子代理、工具执行管线、沙箱与审批策略、会话日志、Skills 与 MCP，离线可用。

03

一键启动 · 自动端口

双击即启动 dsh web，由系统分配空闲端口，仅绑定 127.0.0.1 回环；原生窗口加载 Web UI，不对外暴露服务。

04

双通道自动更新

官方 dsh 更新走 staging 目录 + overlay 原子切换，失败一键回退；客户端自更新走 GitHub / Gitee 双源，分片自动合并。

05

文件变更追踪与还原

聚合会话内全部文件改动，行级 diff 展示新建 / 修改 / 删除；逐文件或全部还原，内容精确匹配，冲突时绝不覆盖。

06

会话内终端

在会话项目目录启动持久 PowerShell，SSE 流式输出、命令历史、断线自动重连，切换标签页与刷新不丢输出。

07

HTML / 端口预览

站内侧边预览面板：会话生成的 HTML 页面实时预览，本地回环端口一键探测并加载，无需离开应用。

08

深度系统集成

托盘常驻、任务完成系统通知、DeepSeek 余额小部件、快捷方式自动维护、退出即清理进程树，不留孤儿进程。

WHY IT SHINES

特性 Capabilities

为深度用户而生的
全栈 AI 开发台

F/01

一键启动

内置独立 Node.js 运行时与 dsh CLI，免配置环境，双击即用。启动时自动挑选空闲端口并仅绑定本机回环，退出时整树回收进程，不留孤儿。

F/02

10 套 UI 皮肤

内置十套视觉主题，深浅自由切换。Web UI 由官方 dsh 引擎驱动，界面能力与官方迭代同步，让工作台贴合你的审美。

F/03

插件市场

基于 dsh-plugin 开放生态，能力随装随用、按需扩展。配套插件（余额小部件、文件变更投影等）随客户端自动同步进 web profile，幂等注册。

F/04

Skills + MCP

Skills 目录一键直达，MCP 工具协议深度集成。工具调用走受管执行管线：沙箱约束、审批策略、行级变更记录，Agent 能力无限外延且全程可审计。

F/05

更新即保障

更新前四目录备份、失败自动回滚，更新中断不丢数据。内置结构化日志 + PII 三层脱敏 + 一键诊断包，报障不再需要手动翻日志。

F/06

双平台覆盖

Windows 安装版 / 便携版（数据随 exe 携带，拷 U 盘即用），Linux 覆盖 deb / rpm / pacman / AppImage 全系包格式，CI 自动构建发布。

快速版本迭代

SHIPPING FAST

版本迭代 Releases

Windows / Linux 双线并进

自 2026-08-14 首发以来几乎每日一更：安装器、更新器、内核与 UI 修复持续滚动发布， 每一次更新都带 备份 + 自动回滚 保障，迭代快而不险。以下为 GitHub Releases 全部里程碑。

  1. v1.0.0
    首发版本 08-14 WIN

    将官方 dsh 打包为开箱即用 Windows 客户端：免装 Node、无边框窗口与托盘、10 套 UI 皮肤、文件变更追踪与一键还原、会话内终端、插件市场、Skills + MCP 迁移、双源自动更新。

  2. v2.0.0
    生态初建 08-15 WIN

    内置插件市场 dsh-webui-market（一键安装 / 卸载插件）、工具视觉模型 dsh-tool-vision、长期记忆组件，功能外延正式起步。

  3. v2.0.2
    更新网络栈重写 08-15 WIN

    自动更新改走系统代理与 CA 证书，支持断点续传，175MB 大安装包不再因网络中断而失败。

  4. v2.0.4
    断线自动重连 08-15 WIN

    HTTP Range 续传 + 指数退避重试，ERR_CONNECTION_RESET 后从断点继续下载，直连 GitHub 也不再慌。

  5. v3.0.0
    更新路径重写 08-16 WIN

    更新器自恢复、右侧栏、端口预览；同日 v3.0.1 重构安装器流程并新增历史节点。

  6. v3.0.1
    安装器重构 + Linux 首版 08-16 LINUX

    全新安装器流程、历史节点；v3.0.1-linux 覆盖 Arch 等发行版，双平台格局成形。

  7. v4.0.0
    稳定性大修 08-17 WIN

    退出进程树等待 killTreeAndWait、安装包 SHA-256 校验、企微 ClawBot 接入、多账户与会话删除。

  8. v4.1
    流式修复 08-17 LINUX

    llm/stream 异步生成器崩溃修复、updater 挂起修复、设置导航修复；Linux 平台同步跟进 v4.0.2 / v4.1.0。

  9. v4.4
    备份回滚机制 08-19 LITE

    更新前 4 目录备份、失败自动回滚；Skills 目录修复；结构化日志 + PII 脱敏；同日发布 v4.4-lite 精简版（余额小部件、低谷价格提醒）。

  10. v4.4.1
    最新版 08-20 WIN

    当前最新 Windows 版本：安装版 + 便携版，配套 SHA256SUMS 校验。迭代仍在继续，下一站已在路上。
